# Правила текста статьи

Правила обязательны для каждого абзаца статьи и отчёта. Нарушение исправляется до проверки
содержания.

## 1. Язык

1. Русский академический: термин, утверждение, обоснование. Порядок слов — русский: подлежащее
   и сказуемое рядом, определение перед определяемым, новое — в конце предложения.
   - плохо: «Мы используем для проверки инвариантов фаззинг» (калька с английского порядка);
   - хорошо: «Инварианты проверяются фаззингом».
2. Без подстрочного перевода. Замены:

   | Не писать | Писать |
   |---|---|
   | имплементация, имплементировать | реализация, реализовать |
   | валидировать | проверить |
   | аутперформит, превосходит бейзлайн | даёт результат выше исходного метода |
   | в терминах X | через X |
   | адресовать проблему | решать задачу |
   | в рамках данной работы | в работе |
   | является | тире или глагол по смыслу |
   | на ежедневной основе | ежедневно |
   | играет ключевую роль | определяет, задаёт (и что именно) |

3. Устоявшиеся термины области не переводятся: байткод, фаззинг, EVM, Lean, Solidity. При первом
   упоминании английский эквивалент даётся в скобках один раз.

## 2. Обороты, которых в тексте нет

- противопоставления-развороты: «не X, а Y», «это не просто X»;
- подводки: «важно отметить», «стоит подчеркнуть», «как известно», «давайте рассмотрим»;
- оценки: «мощный», «элегантный», «революционный», «впечатляющий»;
- риторические вопросы и восклицания;
- тройки однородных слов ради ритма;
- обещания вместо результата: «мы покажем», «будет продемонстрировано».

## 3. Утверждения

1. Число в тексте — из файла результатов, с единицами и условиями получения.
2. Утверждение о чужой работе — со ссылкой `[N]` на запись в `lit/lit.md`.
3. Утверждение о собственном результате — со ссылкой на таблицу, рисунок или теорему.
4. Аналогия названа аналогией. Гипотеза названа гипотезой.
5. Ограничение формулируется как условие: «вывод неверен, если…».

## 4. Обозначения и термины

Обозначения — только из `GLOSSARY.md`, термины — из `ONTOLOGY.yaml`. Один объект — одно слово
на протяжении всей статьи. Символ вводится при первом появлении.

## 5. Проверка абзаца

Перед сдачей абзаца:
1. убрать слова из раздела 2;
2. проверить каждое число по файлу результатов;
3. проверить, что у каждого утверждения есть обоснование;
4. прочитать вслух: если предложение звучит как перевод, перестроить порядок слов.
