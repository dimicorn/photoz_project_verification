# Глоссарий обозначений

Обозначения статьи, кода и данных. Новое обозначение сначала вносится сюда, затем в текст.
Один символ — один смысл на всю статью.

| Обозначение | Значение | Единицы | В коде или данных |
|---|---|---|---|
| $z_{\mathrm{spec}}$ | спектроскопическое красное смещение | безразмерно | `data[:, 6]`, столбец `z_spec` |
| $z_{\mathrm{phot}}$ | фотометрическое красное смещение (photo-z) | безразмерно | `z_phot`, столбец в `predictions_*.csv` |
| $\Delta z$ | нормализованная ошибка photo-z | безразмерно | `dz = (z_phot - z_spec) / (1 + z_spec)` |
| $\sigma_{\mathrm{NMAD}}$ | нормализованная медианная абсолютная ошибка | безразмерно | `1.4826 * median(|dz - median(dz)|)` |
| $k$ | число ближайших соседей | — | `K = 10` в `src/photoz.py` |
| $\mathrm{feat}_i$ | стандартизованный признак (i = 1..5) | безразмерно | `data[:, 7:12]`, столбцы `feat1..feat5` |
| $\eta$ | доля выбросов | безразмерно | `outlier_frac = mean(|dz| > 0.15)` |

Термины:
- photo-z — фотометрическое красное смещение, оценка $z$ по фотометрическим признакам.
- bias — смещение photo-z, медиана $\Delta z$.
- выброс — объект с $|\Delta z| > 0{,}15$.
- kNN — метод k ближайших соседей, евклидово расстояние по feat1..feat5, photo-z = среднее $z_{\mathrm{spec}}$ соседей.
- Happy A/B/C/D — наборы каталогов галактик SDSS DR12 (Beck et al. 2017).
- A — обучающая выборка; B, C, D — проверочные.
- C — выборка с повышенными ошибками фотометрии.
- D — выборка, смещённая к тусклым и красным галактикам.

Синонимы, которые в статье не используются: фотокрасное смещение, z_photo, ошибка предсказания.
