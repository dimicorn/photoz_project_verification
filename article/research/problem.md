# Постановка задачи

## Что дано
- Обучающая выборка: Happy A (74 950 галактик SDSS DR12, Beck et al. 2017).
- Проверочные выборки: Happy B (74 900, то же распределение), Happy C (60 315, больше ошибок фотометрии), Happy D (74 642, смещена к тусклым/красным).
- Признаки: feat1..feat5 — mag_r и четыре цвета, стандартизованные по среднему и σ Happy A.
- Метод: kNN с k=10, евклидово расстояние по feat1..feat5, photo-z = среднее z_spec 10 ближайших соседей.
- Метрики по dz = (z_phot − z_spec)/(1 + z_spec): bias = медиана dz; σ_NMAD = 1,4826 · медиана|dz − медиана dz|; outlier_frac = доля |dz| > 0,15.
- Результаты предыдущего эксперимента: σ_NMAD(B) = 0,0216, σ_NMAD(C) = 0,0529, σ_NMAD(D) = 0,0830.

## Что требуется
Оценить, как растёт ошибка kNN photo-z при переходе от репрезентативной выборки B к смещённым C и D. Количественно: сравнить bias, σ_NMAD и outlier_frac на трёх выборках.

## Когда результат верен
Команда проверки:
```bash

```
Код 0 — метрики согласованы с predictions, схема данных не нарушена.
Дополнительно: `.venv/bin/python article/checks/check_paper.py` — код 0.

## Гипотезы и правило принятия
- Г1. σ_NMAD растёт: B < C < D.
- Г2. Доля выбросов (|dz| > 0,15) растёт: B < C < D.
- Г3. По модулю bias растёт: |bias_B| < |bias_C| < |bias_D|.

Правило принятия: гипотеза согласуется с данными, если порядок строгий (B < C < D) по всем трём метрикам.
Дата записи гипотез: 2026-11-22, до первого прогона на новых данных.

## Границы
- Верификатор не проверяет физическую корректность photo-z (задача астрофизики).
- Верификатор не проверяет статистическую значимость различий между выборками.
- Стандартная девиация σ_NMAD на B ожидается ≈ 0,02; вне диапазона 0,01–0,08 — остановиться и сообщить.
- Обучение только на Happy A; обучение на B, C, D — утечка данных.
- Результаты не переносятся на другие методы photo-z и другие наборы признаков.
